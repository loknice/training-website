## Опис проекту
Цей сайт присвячений одному з найпоширеніших хижаків родини псових — **лисиці звичайній**. 

Сайт складається з 5 сторінок і повністю адаптивний (працює на комп'ютері та телефоні).

### Використані технології:
- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript (Bootstrap components)

### Структура сайту:
- `index.html` — Головна сторінка
- `pages/morphology.html` — Зовнішній вигляд
- `pages/nutrition.html` — Харчування
- `pages/population.html` — Ареал та популяція (з акордеоном та змістом)
- `pages/photo.html` — Фотогалерея (Bootstrap Carousel)

### Особливості реалізації:
- Семантична верстка
- Адаптивний дизайн
- Інтерактивні елементи Bootstrap (карусель, акордеон, навігація)
- Сучасний дизайн в оранжево-коричневих тонах (тема лисиці)
- Коректна робота навігації між сторінками

## Як запустити проект:
1. Відкрити файл `index.html`
2. Клацнути правою кнопкою → **Open with Live Server**
3. Або відкрити сайт за посиланням (якщо опубліковано)
